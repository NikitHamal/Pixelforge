Start from templates

list_templates browses 32 animated assets; load_template opens one in the studio; append_template_states merges suites.

Quick start

await PixelForge.call('list_templates', { category: 'Heroes' });
await PixelForge.call('load_template', { id: 'hero_male' });
await PixelForge.call('export', { format: 'spritesheet', scale: 2 });

// Any window / iframe
parent.postMessage({ type: 'pf:call', id: 1, tool: 'get_document', args: {} }, '*');

// Discover + click the UI (studio page)
PixelForge.describeUI('frame')
PixelForge.clickUI('frame-add')
