brush

Pro pixel tools

Pencil, eraser, bucket (contiguous/global), line, rect, ellipse, shading, move, eyedropper, X/Y symmetry, brush sizes and a 32-color starter palette you can extend.

animation

Animation states

Idle, walk, run, jump, attack, hurt, death and 13 more presets. Per-frame durations, loop control, onion skin and a live preview that keeps playing while you edit.

layers

Layers & history

Unlimited layers with opacity, visibility, lock and merge. Typed-array snapshots give you 80 levels of undo for pixels and structure alike.

smart_toy

Agent-native

Every action is a schema-described tool. Agents paint with ASCII rows, inspect their work as PNG, and click any control by id.

hub

MCP server surface

JSON-RPC handler for initialize, tools/list, tools/call and resources. Connect a stdio bridge and any MCP client can drive the studio.

ios_share

Export anywhere

PNG, sprite sheet + Aseprite-compatible JSON (Unity, Godot, Phaser, Unreal), animated GIF, SVG, CSS and a lossless project file. Import PNG sheets back.

smart_toyAgent-ready by design

The whole studio is a tool surface. Pixel-perfect, deterministic, inspectable.

Agents don't screenshot-and-guess. They call typed tools, read back pixels as text, render previews for vision models and click any control by its stable id.

text_fields

Paint with text

paint_rows turns ASCII art + a color legend into pixels. LLMs are great at grids; this makes sprite generation reliable and cheap.

visibility

See what you made

get_pixels returns hex rows and bounds; render_preview and render_state return PNG data URLs for multimodal review loops.

ads_click

Navigate the UI

describe_ui lists every element with data-agent-id, label, state and rect. click_ui presses or sets it — pixel-perfect on any screen size.

From JavaScript, an iframe, or a browser automation agent 
// Global API (same registry the console & MCP use)
await PixelForge.call('new_document', { width: 16, height: 16, name: 'slime' });
await PixelForge.call('paint_rows', {
  rows: ['..GGGG..', '.GGLWGG.', 'GGGGGGGG', '.DDDDDD.'],
  legend: { G: '#63c74d', L: '#a8f28a', W: '#fff', D: '#3e8948' }, y: 6, x: 4
});
await PixelForge.call('add_state', { name: 'walk', from_preset: true });
await PixelForge.call('export', { format: 'spritesheet', scale: 2 });

// Any window / iframe
parent.postMessage({ type: 'pf:call', id: 1, tool: 'get_document', args: {} }, '*');
// → { type: 'pf:result', id: 1, ok: true, result: {...} }

// Discover the UI
PixelForge.describeUI('frame')   // [{ id:'frame-add', label:'Add blank frame', rect:{…} }, …]
PixelForge.clickUI('frame-add')
